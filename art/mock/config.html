Security alerts

Once a day, by cron, the module looks up your Magento version and the Composer packages in composer.lock against security advisories (Packagist and CISA Known Exploited Vulnerabilities, by default through Valtry's Advisory API). Only package names leave your server, never versions; the matching happens here. No store URL, no customer data, no keys.

Comma-separated. Leave empty to see alerts in the admin only. Email is sent once per new finding, and again if it becomes exploited.

Exploited vulnerabilities are always emailed. Advisories without a rating count as High.

Valtry (default) asks Valtry's Advisory API, which serves the same Packagist, OSV and CISA data from one request. It receives package names only, never versions, and every answer is signed and verified here. If Valtry is unreachable, slow or answers wrongly, the public feeds are used automatically. Public feeds only never contacts Valtry. Setting the environment variable RUVELO_ADVISORIES_SOURCE=public does the same and wins over this setting.
